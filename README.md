# Project 2: Predictive Modeling and Engineering Optimization
MSPE 49600 Project 2 Repository 
Andrew Ramthun

This project develops quadratic response-surface surrogate models to predict Sector 3 time and top speed as functions of rear-wing angle and rear ride height. The models are validated using unseen test configurations and then used in grid-based and numerical optimization. The final recommended setup is selected using constrained optimization to minimize predicted Sector 3 time while maintaining a minimum predicted top speed of 284.0 km/h.
